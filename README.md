# 🌐 Personal Portfolio Website

A modern and responsive **personal portfolio website** built using **HTML and CSS**. This project showcases my frontend development journey, skills, projects, and social profiles through a clean and visually appealing design.

## 🚀 About The Project

This portfolio website is designed to serve as my personal space on the web where I can introduce myself as a **Frontend Developer**, showcase my work, and provide visitors with ways to connect with me.

The project focuses on practicing core frontend concepts such as:

* Semantic HTML structure
* CSS layouts and positioning
* Flexbox
* Responsive design
* Custom typography
* CSS transitions and hover effects
* Buttons and social media icons
* Circular profile image layouts
* Navigation bars
* Clean UI structure

## 🛠️ Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, animations, and responsiveness
* **Google Fonts** — Poppins typography
* **Font Awesome** — Social media icons

## ✨ Features

* 🎨 Modern dark-themed interface
* 🧑‍💻 Developer introduction section
* 🔗 GitHub and social media links
* 🖼️ Circular profile image
* 📱 Responsive layout
* ✨ Hover effects and transitions
* 🧭 Navigation bar
